## 关于我

我主要关注机器人软件开发与设备侧功能实现。在职项目中，负责机器人本体指令执行、设备功能联调及相关文件适配；在校期间独立完成过无人机自主导航、AGV 多传感器融合导航和 ROS2 智能送药小车等项目。

作品集目前收录 **15 个项目案例**，分为在职开发与校园项目两部分。

## 项目中涉及的技术

- **机器人中间件与仿真：** ROS1、ROS2 Humble、MAVROS、Gazebo、ros2_control
- **编程与视觉：** C++、Python、OpenCV、OCR、ONNX Runtime
- **定位与导航：** robot_localization、EKF、AMCL、move_base、A*、TF
- **嵌入式与通信：** STM32、TI 微控制器、CAN、RS-485、Modbus RTU
- **传感与控制：** IMU、GNSS、激光雷达、编码器、工业相机、伺服控制
- **数据记录：** rosbag、rosbag2
